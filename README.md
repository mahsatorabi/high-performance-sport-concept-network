# Mapping the Intellectual Structure of High-Performance Sport Ecosystem Research

Replication repository for a null-calibrated co-word and thematic-evolution analysis of
high-performance sport research (2013–2025), examining the governance, innovation and
talent-development pillars.

> **Manuscript:** "Mapping the Intellectual Structure of High-Performance Sport Ecosystem
> Research: A Null-Calibrated Co-Word and Thematic-Evolution Analysis of Governance,
> Innovation and Talent Development, 2013–2025"

---

## ⚠️ Data availability — read first

The bibliographic records analysed here were retrieved from **Scopus** under a single
structured query. **Scopus licensing does not permit redistribution of the raw export, and no
Scopus-derived record text (titles, abstracts, author keywords, affiliations) is included in
this repository.**

The query below, together with the retrieval date, is sufficient to reproduce the corpus:

```
TITLE-ABS-KEY(
  ( "sport ecosystem" OR "sport system" OR "sport network" OR "sport value chain"
    OR "innovation ecosystem" OR "entrepreneurial ecosystem" )
  AND
  ( "elite sport" OR "high performance sport" OR "professional sport" OR "athlete*" )
)
```
**Retrieved:** 30 September 2026 → **623 records**

All *derived* artefacts are included: concept inventories, family assignments, network
statistics, null-model results, topic assignments and result tables. These are aggregate
outputs of the analysis rather than bibliographic records.

## Pipeline

Nine stages, executed in order. End-to-end runtime is approximately 20 minutes.

```bash
pip install -r requirements.txt
python scripts/run_all.py
```

| Stage | Script | Purpose |
|---|---|---|
| 0 | `s0_corpus.py` | Corpus construction; licence-boilerplate removal; query-artefact diagnostics |
| 1 | `s1_concepts.py` | POS-aware concept extraction through a seven-stage filter cascade |
| 2 | `s2_semcon.py` | SEMCON: semantic concept-family consolidation |
| 2c | `s2c_verdicts.py` | Manual audit → threshold decision rule |
| 3 | `s3_network.py` | Co-occurrence network; bipartite edge null; configuration-model null |
| 4 | `s4_topics.py` | UMAP + HDBSCAN topic model with c-TF-IDF and contrastive labels |
| 5 | `s5_multiplex.py` | Three-pillar multiplex; null-calibrated coupling; supra-centrality |
| 6 | `s6_temporal.py` | Temporal structure and cross-national inference with FDR |
| 7 | `s7_figures.py` | All figures |
| 8 | `s8_summary.py` | Consolidated headline results |

A model checkpoint (`intfloat/e5-base-v2`) and a spaCy model (`en_core_web_sm`) are downloaded
on first run.

## Method in brief

**Problem.** Co-word analysis of a domain literature retrieved with a single structured query
inherits the query's own vocabulary. In this corpus, search-string terms are 3.67× more
frequent than matched control terms, so an uncorrected network returns the search string as a
finding. Synonymy fragments the network further, and structural claims are usually reported
without nulls.

**SEMCON.** Two-stage concept-family consolidation. Stage 1 applies deterministic
orthographic and plural normalisation. Stage 2 clusters residual lexical synonymy by cosine
similarity between **mean-centred** neural embeddings under **complete linkage**, with a
family-size cap.

Two failure modes motivated the final design, both documented in the manuscript:
- **Connected components chain.** A single spurious edge produced one 132-member family and
  destroyed an integrative concept. Complete linkage makes chaining impossible.
- **Raw embeddings are anisotropic.** Mean cosine between unrelated concept pairs was +0.808;
  mean-centring reduced this to −0.001. Without this, the similarity matrix is uninformative.

**Null calibration.** Edges are admitted against a degree-preserving bipartite swap null.
Modularity and betweenness are tested against a configuration model (300 randomisations).

## Headline results

| Finding | Statistic |
|---|---|
| Field is a genuine community structure | Q = 0.446 vs null 0.220 ± 0.004, **z = +64.3** |
| Integrative concepts invisible in framing | Only **8.3%** of mentions in titles; ρ = **0.39** |
| Three pillars are **segregated** | Boundary crossing 0.950 vs null 0.963 ± 0.003, **z = −4.16** |
| Bridging belongs to the system | Pillar × bridging χ² = 2.40, **p = .30** (no pillar differs) |
| National cultures differ | χ² = 180.6, **V = 0.267**, p < .001 |
